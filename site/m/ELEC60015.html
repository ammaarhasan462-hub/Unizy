Example ELEC60015 question

Consider the following F code. let x = 10 let f y = x + y let x = 20 let g = f 5 let h = let x = 3 in f x + x (a) State the values of g and h, showing your reasoning. [4] (b) Explain why the second binding of x does not affect f. [3] (c) Inside a function body, a student writes let mutable c = 0 followed by let inc () = c <- c + 1. State what the compiler does and give a correct alternative. [3] [10 marks]
